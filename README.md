## A few things I've built

### [Claim Circle](https://chromewebstore.google.com/detail/claim-circle/ominadfbilailbklmclcmdbpmckckdad)

I see a lot of misinformation online, and fact-checking felt like too much work: copy the post, switch tabs, ask an AI, then find the sources. So I built a Chrome extension that lets you **circle a post with your mouse and fact-check it right there**. No tab switching or copy-pasting. It has attracted around **500 organic users** and serves **~70 weekly active users**.

### [Clean My Inbox](https://github.com/Rishi94523/Gmail-cleanup)

An inbox cleaner shouldn't decide that an email is unimportant just because it looks like a newsletter. I built an **LLM agent that learns what matters to each user**, asks when it's unsure, and uses those preferences to clean up low-priority emails daily. It supports reversible archiving and approved unsubscribe requests, with Gmail API integration and scheduled runs on Google Cloud Run.

### [A voice agent for finding a flat](https://github.com/Rishi94523/talkdesk-hackathon)

What if an AI agent could find your next flat, schedule visits, and negotiate rent while you sit back? I built a voice-based agent that helps prospective tenants find properties, communicates with landlords to coordinate visits, and negotiates on their behalf. **This project won a hackathon.**

### [Proof-of-Useful-Work CAPTCHA](https://github.com/Rishi94523/useful-work-admission)

CAPTCHAs make people spend time proving they should be allowed in. I wanted to explore whether that computation could do something useful instead. This **patent-pending research project** investigates browser-based useful computation, including distributed ML inference and molecular docking, as an alternative to disposable proof-of-work. A big part of the work is figuring out how to verify results from untrusted clients without spending as much effort as doing the work yourself.
